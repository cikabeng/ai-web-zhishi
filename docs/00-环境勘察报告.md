### 3.1 Git 安装与迁移记录（2026-10-20）

**结果：Git 现在只在 E 盘，C 盘零残留。**

| 项 | 值 |
|---|---|
| 版本 | `git version 2.55.0.windows.5` |

| 数字签名 | 有效，签名人 `CN=Johannes Schindelin`（Git for Windows 维护者） |
| 功能验证 | 已实测 `init / config / add / commit / log`，生成提交 `c9021af`，通过 |

**过程（供复盘）**

1. 最初用 `winget install Git.Git` 装到了 `C:\Program Files\Git`（404 MB，管理员级安装）。
2. 要求迁到 E 盘时发现：当前会话非管理员，删不掉 Program Files；且该机器上 `curl`/`Invoke-WebRequest` 在沙箱内无法完成 HTTPS（`SEC_E_NO_CREDENTIALS`），GitHub 直连下载仅约 6 KB/s。
3. 改用国内镜像 `registry.npmmirror.com` 下载（62 MB / 19 s），签名校验通过。
4. 提权卸载了 C 盘版本，但 Git 安装器的 `/DIR` 参数未被采纳（文件落到了 `%LOCALAPPDATA%\Programs\Git`），随后多次非提权运行安装器/自解压程序均静默退出码 1、无日志。
5. 最终方案：**提权运行 PortableGit 自解压包**，解压到 `E:\Apps\PortableGit`（成功的关键是提权；同一命令非提权执行会被静默拒绝）。
6. 清理：C 盘两份 Git（Program Files 与 LocalAppData）均已删除；工作区 `.cache` 内约 118 MB 安装包已清理。

**绿色版的取舍**

- 优点：不写注册表、不占 C 盘、换版本只需替换目录、拷走即可用。
- 代价：没有开始菜单项、右键菜单、系统"卸载"入口（删除目录即卸载）。
- 若后续一定要标准安装版（例如演示时展示常规安装流程），可以在有管理员权限且网络良好的环境下重装到 `E:\Apps\Git`；功能上两者没有区别。

> PATH 变更对**新启动**的终端生效。本 GUI / 已开着的终端需重启才能直接敲 `git`。

## 5. 由环境反推的技术约束

1. **没有 Docker ⇒ 向量库必须能嵌入式跑**。选 `qdrant-client` 本地模式（同一套 API，后续可无缝切服务端），而不是 Milvus / Elasticsearch。
2. **Python 3.13 较新 ⇒ 默认不碰 torch**。`sentence-transformers` / `FlagEmbedding` 依赖 torch，cp313 轮子虽有但体积大（>2 GB）、易出兼容问题。**默认走 API 做 embedding 与重排**，本地模型只作可选降级。真要用本地，再单独建 3.11 venv。
3. **没有 API Key ⇒ 代码必须做模型适配层**，并且提供一个离线可跑的"假模型"模式（确定性哈希向量 + 固定模板回答），保证没有 key 时管线、测试、界面都能开发，不至于全阻塞。
4. **8 GB 显存 ⇒ 可选项**：本地跑 bge-small/bge-base、Qwen2.5-3B 量化都够；但不要作为主路径。
5. **C 盘只剩 33 GB ⇒ 缓存目录要改**：`pip` 缓存、`npm` 缓存、HuggingFace 缓存全部指向 `D:` 或 `E:`。
6. **npm 用官方源**：国内可能偏慢，装依赖时可临时切 `registry.npmmirror.com`，但要提交 `package-lock.json`，保证评审可复现。
