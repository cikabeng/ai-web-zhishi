### 6. 演示模式与大模型接入（10-21 20:29–20:35，8 次提交）

```
a8e125c  feat(frontend): 全局演示模式横幅
a9c906a  docs: 更新测试数量与交付说明
1e793a4  feat(config): DEMO_MODE 强制开关，模型 API 故障时可切演示模式
39520e1  docs: 补充演示模式兜底与交付说明
08c1da3  feat(llm): OpenAI 兼容调用层与提示词，教学引擎 L1-L3 接入并支持回退
8924d85  test(llm): 提示词约束、客户端容错与回退标记，共 8 个用例
aa04c7a  feat(frontend): 显示模型生成/模板生成/回退状态
15a6f8c  docs: 模型接入生效范围与回退行为
```

**关键决策**：AI 功能必须真实接入，但不能因为 API 故障就表演示不出来。因此先做演示模式横幅与强制开关，再接模型；模型只润色 L1–L3，L4 固定题库不改写；失败一律回退模板并在页面标注来源（`model` / `template` / `fallback`）。8 个测试分别锁住提示词约束、越界引用剔除、故障回退与"模型只看得到被引用片段"。

### 7. 安全加固与通用知识层（10-21 20:44–20:59，6 次提交）

```
1064e58  chore: 移除误提交的空文件 .ven
f844a91  fix(teaching): 只把被引用的片段交给模型，并剔除越界引用编号
d892972  test: 测试强制演示模式且不读本机 .env，避免真实调用外部 API
748a458  feat(knowledge): 通用错误诊断层 + 证据覆盖度判定，避免资料只沾边时拒答
1e2ced1  feat(frontend): 资料覆盖度徽章与通用知识提示
dce7be4  test: 通用知识层与覆盖度场景，共 6 个用例
7e33c04  docs+data: 新增 Python 类型错误专题资料与标准用例，更新交付文档
```

两处安全加固：① 传模型前只保留被引用片段，并清洗模型输出里的越界引用编号，杜绝"编造引用"；② 测试强制演示模式时不读本机 `.env`，保证测试绝不触发外部 API 调用。

一处产品判断：课程资料永远覆盖不全，"资料没写就只会拒答"对学生没帮助。因此新增**通用知识层**，对 13 类常见 Python 报错给出诊断，但界面明确标注「通用 Python 知识（非课程资料）」；同时引入**证据覆盖度判定**，避免关键词"沾边"就被误判为有据可依。

### 8. 教学前端体验优化（11-15 15:36，1 次提交）

```
8f2b615  feat(teaching): 引导模式 L3 提交弹窗、模式悬浮说明、引用折叠与左侧竖向进度栏
```

把已有的 L3 提交门槛做成明确的交互弹窗，加入模式说明、引用折叠与左侧进度栏，让学生清楚"我现在在哪一层、为什么还不能看示例、依据是哪一段"。
