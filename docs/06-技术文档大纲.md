## 1 项目概述（2 页）

- 1.1 背景：学生把代码丢给通用 AI → 抄答案、知识没学会、AI 还会编
- 1.2 产品定位：只依据课程资料作答，每条结论带可核对引用
- 1.3 四条底线：有据可查 / 无据则明说 / 引导优先 / 演示模式诚实
- 1.4 作品形态：Web 应用（Vue 3 前端 + FastAPI 能力层），4 个页面
- 配图：`docs/assets/teaching-l1.png`

## 2 需求分析（3 页）

- 2.1 用户角色：学生（主要）、教师/管理员（资料维护）
- 2.2 功能需求：知识库导入与检索、六类问题分类、L1–L4 分层提示、L3 提交门槛、提交反馈、截图报错分析、资料覆盖度提示
- 2.3 非功能需求：离线可跑、不执行用户代码、密钥不出后端、引用可核对、10 分钟复现
- 2.4 需求边界：不做代写、不做完整实现、无登录与多租户

## 3 系统架构设计（4 页）

- 3.1 总体架构：前端（Vue3/Vite/TS）→ HTTP/JSON → FastAPI → 领域模块 → Chroma / 文件系统
- 3.2 后端模块：`core`（配置）、`library`（入库索引）、`retrieval`（混合检索）、`knowledge`（通用知识）、`teaching`（引擎）、`errors`（OCR 与分析）、`llm`（模型客户端）、`api`（协议）
- 3.3 检索链路：`CompositeRetriever` 先查 `LibraryIndex`（Chroma 向量 + 字面覆盖加权），不足时回落 `KeywordRetriever`（内置示例）
- 3.4 请求数据流：问题 → 分类 → 检索 → 引用构建 → 证据覆盖度判定 → 分层提示 → 护栏 → 模型润色（可选）→ 响应
- 3.5 部署形态：本地双服务，Vite 代理 `/api`

## 4 AI 技术方案（7 页，重点章节）

- 4.1 **技术选型与理由**：OpenAI 兼容协议（可换供应商）、pydantic-settings（环境变量）、Chroma（本地持久化）、离线哈希向量（无 GPU/无外网）、rapidocr（离线 OCR）、不引入 LangChain（链路可控、依赖少）
- 4.2 知识表示：字符 n-gram 哈希映射到 512 维向量；`hash-char-ngram-v1`；余弦相似度 + 字面覆盖率加权（`0.75 / 0.25`）；分块 500/80/800；集合 `library_chunks_v1`
- 4.3 **集成方式**：`llm/client.py` 封装 OpenAI 兼容调用与重试；仅 L1–L3 由模型润色，L4 固定题库；失败回退模板并标注 `llm_status`；只把被引用片段交给模型；剔除越界引用编号；`DEMO_MODE` 三级开关（auto/on/off）
- 4.4 提示词约束：只依据资料、不得输出完整实现、引用编号必须可核对、按层级输出、输出 JSON 结构
- 4.5 证据覆盖度：关键词命中标记 + 覆盖度判定，资料只沾边时不误判为有据；无覆盖时走通用知识层
- 4.6 **优化策略**：混合检索加权、分块重叠从句子边界开始、sha256 去重、删除同步清向量、只传被引用片段降低 token 与幻觉、失败降级不中断、模型与模板分离标注
- 4.7 常见问答：为什么 `embed_dim` 回显 1024 而实际向量 512（配置为将来接语义 Embedding 预留，实际 `EMBED_DIM=512`）；为什么不用语义模型（离线可跑、评委会零配置复现）
- 4.8 安全与可控：不执行用户代码、DOMPurify、密钥只在后端、`/api/health` 只回布尔值

## 5 核心功能实现（6 页）

- 5.1 课程知识库：上传（20 MB / 300 页 / PDF·DOCX·TXT·MD）→ 解析 → 分块 → 索引 → 去重 → 删除同步 → 重建 → 分块预览
- 5.2 六类问题分类与四级提示：concept/error/experiment/sql/web/assignment；L1 知识点提示 / L2 解题思路 / L3 局部示例 / L4 相似例题
- 5.3 引导模式 L3 提交门槛：未提交尝试时 `clamp_reason = guided_requires_attempt`，前端弹窗提示
- 5.4 通用知识层与覆盖度徽章：13 类常见 Python 报错诊断，明确标注「通用 Python 知识（非课程资料）」
- 5.5 截图报错分析：四通道 OCR（auto/vision/rapidocr/none）、图片校验、识别结果可编辑、复用检索与教学引擎
- 5.6 前端交互：首页、教学页（层级阶梯/引用折叠/进度栏/模型状态）、报错页、知识库页
- 配图：`docs/assets/library.png`、`docs/assets/errors-demo.png`

## 6 测试与部署（4 页）

- 6.1 测试体系：**124 个用例**，15 个测试文件，覆盖配置/知识库/检索/分类/层级/护栏/通用知识/LLM/报错/OCR/接口
- 6.2 测试纪律：强制演示模式测试不读本机 `.env`，杜绝测试触发外部 API
- 6.3 自检与构建：`check_demo.py` **6/6 PASS**；`npm run build` 通过（vue-tsc 无错）
- 6.4 部署与复现：5 步 ≤10 分钟（venv → 依赖 → `.env` → seed → dev.ps1）；服务端口 8000 / 5173
- 6.5 回退预案：模型 API 故障时 `DEMO_MODE=on` 重启，检索与引用不受影响
- 6.6 实测证据：`llm_status:"model"`、`demo_mode:false`、124 passed（见 `docs/assets/health-check-evidence.md`）

## 7 总结与展望（3 页）

- 7.1 **技术创新点**：引导式分层教学（拒绝代写）+ 证据覆盖度与通用知识分层 + 引用强制与泄露护栏 + 混合检索零依赖
- 7.2 **应用创新点**：面向软件工程实训的"负责任 AI 助教"；截图报错即问；10 分钟极速复现；演示模式诚实标注
- 7.3 局限：无 SSE、无独立聊天页、无 Agent/工具调用、哈希向量非语义、L4 固定题库、提交反馈仅关键词级
- 7.4 后续：语义 Embedding、流式渲染、评测指标看板、多帧报错诊断
